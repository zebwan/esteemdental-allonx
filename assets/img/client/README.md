# Client photos to request from Esteem Dental

Drop the files here using these exact names, then update the matching
`<img src>` in `index.html` (each one is marked with a `SWAP →` comment).

| filename | what to ask for | crop |
|---|---|---|
| `allonx-case.jpg` | a finished All-on-X bridge from one of their own cases | landscape, ≥1400px wide |
| `cbct.jpg` | an OPG or CBCT screenshot from a real planned case, patient identifiers removed | portrait 3:4 |
| `clinic.jpg` | the actual clinic interior, or the clinical team | portrait 4:5, ≥1400px wide |
| `before-after-1.jpg` | a consented before/after of a real full-arch case | landscape 4:3 |

Until these arrive the page uses licensed stock from Pexels, which is accurate
but generic. Real case photography is the single biggest trust upgrade available
to this page — especially the before/after.

**Consent:** before/after and any identifiable patient image needs written
patient consent on file, and the MDC guidance on advertising applies.
